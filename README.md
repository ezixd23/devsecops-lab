# DevSecOps Lab

Personal DevSecOps lab built to practice and demonstrate practical, end-to-end
security integration across the software delivery lifecycle: CI/CD, Infrastructure
as Code, container security, supply chain security, Kubernetes, and cloud security
on Azure — all at zero cost.
